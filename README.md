# Broom
Ultra fast Janitor/Trove/Maid alternative.

# Benchmarks
Benchmarks are conducted by recording the time it takes to add and clean 100K objects. The GC test is done by creating/destroying and adding 10K objects to 10 new scopes every frame. This test shows the actual performance impact of the GC churn generated by the cleanup module. Note a table with an empty cleanup function is used for the Cleanup Test in order to isolate the actual cleanup cost of the module. All tests are done in studio.

### Add Test

| Cleanup Tool | Time Taken (ms) 
|--------------|--------------
| Janitor | 33.39
| Maid | 24.78
| Trove | 42.08
| Scythe | 25.77
| Broom | 11.98
